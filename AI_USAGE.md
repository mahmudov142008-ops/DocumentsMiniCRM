## 4. Technical Decisions Made During Development

| Decision | Rationale |
| :--- | :--- |
| Use `@hello-pangea/dnd` over `react-beautiful-dnd` | Active fork with React 19 compatibility and TypeScript support |
| Custom SVG donut chart over Recharts | Eliminates an extra bundle dependency; simpler rendering; chart logic is 30 lines of pure geometry |
| Optimistic UI with rollback for Kanban moves | Gives instant drag feedback; gracefully recovers on network failure |
| CSS Custom Properties Design Token system | Full design fidelity without TailwindCSS dependency; all tokens defined in `tokens.css` |
| `verbatimModuleSyntax: false` | Required because Vite's newer TypeScript config defaults differ from what Jest-DOM type augmentation requires |
| Import `vitest/config` in `vite.config.ts` | Resolves TypeScript error `'test' does not exist in type 'UserConfigExport'` |
| Notes filtered server-side with `.eq('customer_id')` | Prevents notes from appearing under wrong customers; backed by FK constraint |

## 5. Bugs Discovered and Fixed by AI

See full documentation in [`BUGS_AND_FIXES.md`](BUGS_AND_FIXES.md).

Summary of issues identified and resolved autonomously by the AI during this session:
1. `verbatimModuleSyntax: true` caused TS1484 errors — resolved by switching to `false`
2. `defineConfig` from `vite` rather than `vitest/config` caused TS2769 — resolved with correct import
3. `@testing-library/jest-dom` matchers not recognized by TypeScript — resolved with explicit import from `/vitest` subpath
